# Study With Friendly — Android Studio project

1. Extract this ZIP file.
2. Open the `android-studio` folder from Android Studio.
3. Accept the Gradle sync prompt and choose an Android device or emulator.
4. Press **Run**.

The learning portal is packaged inside the app, so the core screens work without a hosted website. Data added through the admin flow stays on that device. The admin demo login is `bharath` / `Bharath@123`.

The first build copies the current web assets from the project root to the Android app assets automatically. Keep the `android-studio` folder beside `index.html`, `styles.css`, `app.js`, and `icons` as supplied in this ZIP.
