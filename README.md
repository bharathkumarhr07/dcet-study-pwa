# ನನ್ನ ಟಿಪ್ಪಣಿಗಳು PWA

GitHub Pages ನಲ್ಲಿ ಹೋಸ್ಟ್ ಮಾಡಬಹುದಾದ ಸರಳ offline-first Kannada notes app.

## Publish with GitHub Pages

1. ಈ ಫೋಲ್ಡರ್ ಅನ್ನು ಹೊಸ GitHub repository ಗೆ push ಮಾಡಿ.
2. Repository **Settings → Pages** ತೆರೆಯಿರಿ.
3. **Deploy from a branch**, branch `main`, folder `/ (root)` ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು Save ಒತ್ತಿ.
4. ಕೆಲವು ನಿಮಿಷಗಳ ನಂತರ GitHub ತೋರಿಸುವ URL ನಲ್ಲಿ app ಲಭ್ಯವಾಗುತ್ತದೆ.

HTTPS ಇರುವ GitHub Pages URL ನಲ್ಲಿ ತೆರೆಯುವಾಗ install option ಬರುತ್ತದೆ. Notes browser local storage ನಲ್ಲಿ ಉಳಿಯುತ್ತವೆ.
